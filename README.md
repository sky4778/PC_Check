# AI 電腦設備檢查站
單頁式靜態網站：偵測電腦、評分、檢查能否跑 Ollama／Stable Diffusion／熱門遊戲，並產生 AI 分析提示詞。AI 規則見 [CLAUDE.md](CLAUDE.md)。

## 本機預覽
直接用瀏覽器開啟 `index.html`（網路延遲測量需部署後才準確）。

## 部署 GitHub Pages
1. 建立 Public repo 並上傳全部檔案
2. Settings → Pages → Deploy from a branch → `main` / `(root)`
3. 網址：`https://<帳號>.github.io/<repo>/`
